# SPYA Website

Website redesign for South Parkland Youth Association.

[View the Website](https://atalwar0312.github.io/spya-redesign/)

## Project Structure

| Location | Contents |
| --- | --- |
| `index.html` | Homepage |
| Other `.html` files | Sports, registration, and information pages |
| `assets/` | Images and other website assets |
| `css/` | Website styling |
| `js/` | Interactive features |
| `data/` | Website content and source material |
| `scripts/` | Build and validation tools |
| `docs/` | Project documentation and content reviews |

## Publishing

The website is published through GitHub Pages. HTML pages remain at
the repository root to preserve existing links.

Temporary publishing folders and local backups are not part of this
repository.
